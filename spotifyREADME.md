# Spotify Data Analysis using Python

Exploratory data analysis and visualization of Spotify listening/track data, built to uncover patterns in music trends, popularity, and audio characteristics.

## Why I built this
Spotify's dataset is a great playground for practicing end-to-end EDA — cleaning real-world data, engineering insights, and visualizing them clearly. This project focuses on turning raw track-level data into interpretable trends.

## What's inside
- Data cleaning and preprocessing of raw Spotify track data
- Exploratory analysis of features like popularity, genre, danceability, energy, and tempo
- Visualizations highlighting trends and correlations between audio features
